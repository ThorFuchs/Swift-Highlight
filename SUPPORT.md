# Support

Use [GitHub Issues](https://github.com/ThorFuchs/Swift-Highlight/issues) for
bugs, questions, and focused proposals when the repository is public. Include
the package commit or version, Swift toolchain, platform, language, a minimal
input, the API called, and expected and actual results. Remove private data.

For vulnerabilities use [SECURITY.md](SECURITY.md), not a public issue. No
response time or long-term support window is promised.
